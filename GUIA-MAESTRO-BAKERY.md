# Guía del maestro: Bakery Vocabulary

Esta guía acompaña el tema **Bakery vocabulary** de Grammar Rush. Divide a los alumnos por nivel y selecciona `Bakery vocabulary` junto con su nivel antes de iniciar la ronda.

## A1 — reconocer y pedir productos

**Objetivo:** nombrar productos básicos, usar plurales y hacer pedidos corteses.

| English | Español |
|---|---|
| bread | pan |
| loaf / loaves | hogaza / hogazas |
| bread roll | bolillo o panecillo |
| slice of cake | rebanada de pastel |
| cookie | galleta |
| muffin | muffin o panqué individual |
| cake | pastel |
| oven | horno |
| fresh | fresco |
| warm | caliente o tibio |

**Frases:** `I would like two bread rolls, please.` · `Can I have a slice of cake?` · `These cookies are fresh.`

**Puntos de atención:** `loaf → loaves`; `this/is` para un producto; `these/are` para varios.

## A2 — comprar y describir

**Objetivo:** preguntar precios, cantidades, tipos de pan y hacer solicitudes en la panadería.

| English | Español |
|---|---|
| baguette | baguette |
| pastry | pastelito o pieza de repostería |
| croissant | croissant |
| wholemeal bread | pan integral |
| gluten-free | sin gluten |
| pack / wrap | empacar / envolver |
| separately | por separado |
| chocolate filling | relleno de chocolate |
| icing | glaseado |
| display case | vitrina |

**Frases:** `Do you have any wholemeal bread?` · `How much is this croissant?` · `Could you pack the pastries separately, please?`

**Puntos de atención:** singular/plural, `how much` para precios y `could you + verbo` para solicitudes.

## B1 — textura, ingredientes y procesos

**Objetivo:** describir panes y repostería con precisión y explicar procesos.

| English | Español |
|---|---|
| sourdough | masa madre |
| rye bread | pan de centeno |
| crust | corteza |
| crumb | miga |
| chewy | correoso o de textura elástica |
| airy | aireado |
| crisp | crujiente |
| dough | masa |
| knead | amasar |
| rise | levar o subir |
| filled with | relleno de |
| topped with | cubierto con |

**Frases:** `The sourdough has a chewy crust and an airy crumb.` · `This pastry is filled with raspberry jam and topped with icing.`

**Puntos de atención:** `recommend + -ing` (`The baker recommended trying...`); `there are fewer cupcakes`; voz pasiva para describir productos.

## B2 — lenguaje técnico y formal

**Objetivo:** comprender vocabulario profesional y estructuras avanzadas de recetas y producción.

| English | Español |
|---|---|
| patisserie | pastelería fina |
| viennoiserie | bollería francesa laminada |
| laminated dough | masa laminada |
| proof | fermentar o levar la masa |
| batch | tanda o producción |
| shelf life | vida útil |
| allergen | alérgeno |
| recipe calls for | la receta requiere |
| kneaded | amasado |
| evenly | uniformemente |
| sell out | agotarse |

**Frases:** `Had the dough been kneaded longer, the bread would have risen more evenly.` · `The recipe calls for the butter to be softened.` · `The patisserie specializes in viennoiserie.`

**Puntos de atención:** inversión condicional (`Had...`), `no sooner...than`, `call for + object + to-infinitive` y vocabulario técnico.

## Secuencia sugerida de clase (40–50 minutos)

1. **Activación — 5 min:** muestra o dibuja 6 productos y pide que los nombren.
2. **Presentación — 10 min:** enseña únicamente el vocabulario de la tabla del nivel del grupo; modela pronunciación y repite en coro.
3. **Práctica — 10 min:** parejas: un alumno es cliente y otro dependiente. Cambian roles después de tres pedidos.
4. **Grammar Rush — 15 min:** selecciona `Bakery vocabulary` y el nivel del grupo. Explica que deben decidir si la oración es `Correct` o `Incorrect` y apostar una cantidad.
5. **Cierre — 5 min:** después de cada explicación, pide que un equipo reformule la oración y dé un ejemplo propio.

## Uso recomendado del juego

- Para grupos nuevos, usa A1 o A2 y activa la mezcla únicamente de Bakery vocabulary.
- Para universidad, combina Bakery vocabulary con `In a café`, `Polite requests` y `Customer–clerk conversations`.
- Usa el modo offline si la conexión de los celulares es inestable: el maestro agrega los equipos y registra desde la laptop la apuesta y la respuesta de cada grupo.
- Cambiar el nivel o el tema durante la partida aplica a la siguiente pregunta; la pregunta actual conserva su mezcla original.
- No enseñes todas las palabras en una sola sesión. Elige 8–12 palabras y deja las demás como extensión.
